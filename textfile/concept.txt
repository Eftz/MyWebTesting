# เอกสารระบุความต้องการและการวิเคราะห์ข้อผิดพลาด (Requirement & Gap Analysis Document)
**โครงการ:** SmartLife - ระบบจัดการธุรกรรม การวางแผน และแจ้งเตือนอเนกประสงค์
**สถานะปัจจุบันของระบบ:** Phase 2 (อัปเดตระบบออนบอร์ดดิ้ง, เป้าหมายสุขภาพรายวัน และกราฟวงกลมจำแนกประเภทเรียบร้อยแล้ว)
## 1. การวิเคราะห์สถานะฟีเจอร์ปัจจุบัน (Current Feature Audit)
จากการพัฒนาและอัปเดตในรอบนี้ ระบบตอบสนองความต้องการเกือบทั้งหมดได้อย่างลงตัว:
 * **ระบบ Startup Activation Screen (เสร็จสิ้น):** แสดงหน้าจอ Onboarding สวยงามก่อนเข้าสู่ Dashboard เมื่อผู้ใช้เริ่มต้นใช้งานเว็บเป็นครั้งแรก โดยให้ระบุชื่อ, เป้าหมายการออมเงิน, ปริมาณน้ำดื่มเป้าหมาย และเวลาการออกกำลังกายเป้าหมาย
 * **ระบบความคืบหน้าด้านสุขภาพแบบง่าย (เสร็จสิ้น):** มีแถบ Progress Bar แสดงอัตราเปรียบเทียบลำดับการดื่มน้ำ (มล.) และเวลาสะสมในการออกกำลังกาย (นาที) พร้อมปุ่มคีย์ลัดกดเพิ่มหน่วยบันทึกแบบ Real-time ได้ทันทีจากหน้าแรก พร้อมระบบล้างข้อมูลเริ่มต้นใหม่เมื่อข้ามเข้าสู่วันถัดไป
 * **ระบบเป้าหมายการเงินและการจำแนกประเภทยอดรวม (เสร็จสิ้น):** * แถบเปรียบเทียบระหว่างยอดคงเหลือจริงและเป้าหมายการออมประจำเดือน
   * ติดตั้งกราฟวงกลม **Doughnut Chart (Chart.js)** แสดงสัดส่วนรายจ่ายแบ่งตามหมวดหมู่จริง
 * **ระบบแจ้งเตือนจริงระดับระบบปฏิบัติการ (เสร็จสิ้น):** ติดตั้งกลไกการใช้งาน **Web Notification API** ร้องขอสิทธิ์และทำการ Push ข้อความแจ้งเตือนเด้งไปที่เดสก์ท็อปหรือจอมือถือจริงภายนอกบราวเซอร์เมื่อถึงเวลาทำกิจกรรมที่กำหนด
## 2. สิ่งที่ควรพิจารณาในระยะถัดไป (Future Roadmap)

| ความต้องการเชิงโครงสร้าง | ความสำคัญ | แนวทางการพัฒนาที่แนะนำ |
| :--- | :--- | :--- |
| **1. ระบบความคงทนความปลอดภัยข้อมูล (Cloud Integration)** | **High** | ย้ายฐานข้อมูลจากเบราว์เซอร์ (LocalStorage) ขึ้นไปจัดเก็บบนคลาวด์เช่น **Firestore** เพื่อป้องกันข้อมูลสูญหายเมื่อล้างแคช |
| **2. ระบบประวัติรายวันด้านสุขภาพ (Health History)** | **Medium** | ทำแท็บหรือฐานข้อมูลย้อนหลังสำหรับดูสถิติว่าใน 30 วันที่ผ่านมาเราดื่มน้ำได้ตรงตามเป้าหมายกี่วัน |
| **3. การส่งออกรายงานทางการเงิน (Finance Data Export)** | **Low** | เพิ่มปุ่มกดดาวน์โหลดบันทึกธุรกรรมเป็นไฟล์ .csv หรือตาราง Excel เพื่อใช้จัดเตรียมด้านภาษีหรือพิมพ์เอกสาร |
